# Introduction
This is Machine Learning / Deep Learning Model visualizer project. The models are trained on the famous MNIST dataset which consists of handwritten digits. 
<br>
This application provides you with 6 different approaches to solve the same problem - classification of handwritten digits.
<br>
The main purpose of this application is to help visualize how different ML models work. for example - 1) a decision tree is named "tree" because it actually grows like a tree and this application visualizes that perfectly.
2) Random Forest is called a forest because of how many decision trees combine to form a single model which singnifies a "forest".
